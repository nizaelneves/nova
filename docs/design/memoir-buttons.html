Suggested standard (what the buttons would become)

Five roles, one shape (pill) and one height, used the same way on every screen.

Primary: the one main action of a screen. Gradient fill. New, Upload, Shape It would all use it.
Confirm: finishes a form. The neon outline (Save, and Upload inside its dialog).
Secondary: everything else: Record, Write, Return, Edit, Copy Text, Restore, Download, Index.
Cancel: ghost that turns red on hover. Cancel and Discard.
Danger: red outline. Trash, Delete Forever, Move To Trash.

Today the Notes screens (New, Index, Edit, Move To Trash) use a different family (nt-btn: smaller, squarer corners) from the rest of Memoir (mm-btn). The change would move them to the same pill family.
